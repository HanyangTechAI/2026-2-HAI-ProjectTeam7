# 데이터 확보 및 관리

대상은 [AI Hub 103 수어 영상](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=103)입니다. **메타데이터 및 비수지 주석 분석 자료 확보, 실제 학습 데이터 연결 검증 진행 중**입니다.

## 보존한 실제 경로

`final_p0_p3_submission/`에는 manifest_3states.csv, split_manifest.csv, gloss_nms_segments.csv, nms_distribution.csv와 `p0_verified_samples/`의 형태소 JSON 5개가 있습니다. 이 폴더는 팀원 코드의 경로 호환성을 위해 이동·수정하지 않았습니다. CSV 합계는 67,335,714바이트(약 67.3 MB)입니다. JSON 5개는 동일 수행의 각도별 형태소 주석이며 전체 주석이나 키포인트가 아닙니다.

- `raw/`: 향후 승인된 원본 MP4·전체 키포인트·전체 주석을 연결할 로컬 위치. 현재 원본 연결 미검증.
- `processed/`: 향후 생성할 Tensor·정규화 결과. 현재 미구현.
- `../manifests/`: 이전 스키마 제안 안내가 남아 있으며 제공 CSV를 이곳으로 이동하지 않습니다.

새 clone에서 로컬 폴더가 필요하면 `mkdir -p data/raw data/processed`로 생성합니다. 제공 데이터는 Git 기본 제외이므로 별도 승인된 전달 절차로 확보해야 합니다.

## 실제 확인 및 제한

180,000개 영상 메타데이터, 2,000개 문장, 18명 수연자, 573,050개 구간, 비어 있지 않은 Gloss 442종, NMS 표시 5,475구간을 확인했습니다. 구간 없는 영상 60개·잘못된 시간 구간 10개·빈 Gloss 25개·두 그룹의 각도 이상은 추가 감사 대상입니다.

실제 CSV 컬럼, JSON 확인 범위, 분할 및 입력 계약은 [docs/data_schema.md](../docs/data_schema.md)를 따릅니다. keypoint_prefix의 실파일 매칭·FPS·키포인트 JSON 구조는 미확인입니다. 메타데이터의 URL 문자열이 존재해도 원본 파일 접근이나 다운로드 권한을 보장하지 않습니다.

## 이용 조건 및 Git

AI Hub 신청·승인·데이터 사용 조건·개인정보와 원본 재배포 제한을 확인하고 사용합니다. 원본 MP4, 대량 키포인트/주석 JSON, 전처리 Tensor, 가중치·로그·압축파일은 기본 제외합니다. 제공 폴더는 통째로 기본 제외하되 삭제하거나 기존 추적을 해제하지 않습니다. 공개 가능한 소규모 주석 예시는 이용 조건을 확인한 뒤 명시적 예외 경로와 검토 절차를 합의합니다.

CSV는 자동으로 Git에 추가하지 않습니다. 공유 방식은 접근 제어된 별도 저장소를 우선 검토하고 Git LFS 사용 여부는 팀이 결정합니다. 코드·문서·설정·공개 가능한 스키마와 작은 메타데이터는 관리할 수 있습니다.
